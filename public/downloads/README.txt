AETHERX — APK hosting
=====================

Sube aquí el APK firmado con el nombre EXACTO:

    aetherx-latest.apk

El modal de descarga de la web enlaza a /downloads/aetherx-latest.apk.
Mientras el archivo no exista, el botón de Android se mostrará
automáticamente como "próximamente" (deshabilitado) en vez de dar 404.

Para actualizar la versión, basta con reemplazar el archivo por el
APK nuevo — no hace falta tocar código.
